# Day 1 acceptance checklist

- [x] Mobile browser flow: item photo → space photo → result
- [x] Camera and photo-library choices on both capture screens
- [x] Three conservative result states supported by the AI response contract
- [x] Vision request path, with an honest no-key fallback
- [ ] Run the 10 real-person cases in `tests/cases.md`
- [ ] Confirm a new participant can complete the flow without instructions

## Field-test protocol

Ask each participant to choose a real item and destination. Do not explain the interface. Time the task, measure the real fit separately, and complete the matching row in the test log. Mark an answer “unable to judge” when the app says MAYBE; that is a desirable outcome when photos lack a credible reference.
